# Черновой этап домашнего задания

Аргументы (могут быть пустыми): $ARGUMENTS
В аргументах может быть код урока, ссылка на мой репозиторий, который надо взять за основу, или уточнение уровня. Всё, что не указано, решай сам по правилам из CLAUDE.md.

## 1. Найти материалы урока

- PDF урока — во вложениях чата или в папке репозитория. Найди его сам (`*.pdf`), не спрашивай путь.
- Если PDF большой, читай частями (страницы по 10–20). Сначала первые 2 страницы (название, «Результат дня»), потом последние 4–5 — там «Домашнее задание». Середину (теория, практика, код) — после, чтобы найти ошибки урока.
- Если PDF нет, задание берётся из `TASK.md`. Если пуст и он — это единственный вопрос ко мне.
- Скриншоты в PDF — картинки: если в них код или вывод, на которые ссылается задание, посмотри страницу как изображение.
- PDF в git не добавлять (он в `.gitignore`).
- Если в аргументах есть ссылка на мой репозиторий — изучи его структуру, README и HOMEWORK.md, прежде чем решать, что делать.

## 2. Разбор → `NOTES.md`

Заполни разделы «Разбор урока» и «Вопросы ко мне» по восьми вопросам из CLAUDE.md (этап 1). Особенно:
- требования ДЗ — отдельными проверяемыми пунктами, с уровнями и форматом сдачи;
- ошибки урока — с номером страницы PDF, в раздел «Материал для отчёта»;
- что нельзя сделать в облаке — сразу в «Сделать локально».

Вопросы ко мне — максимум три. Если ответы не критичны, не жди их: прими решение, запиши его и продолжай.

## 3. Работа

По правилам этапа 2 из CLAUDE.md. Порядок: структура папок → код → тесты (`pytest`, запусти их здесь) → README.

## 4. Итог

- `NOTES.md`: чек-лист со статусами ✅ / ⚠️ / ❌ по каждому требованию; «Сделать локально» — готовые команды PowerShell; «Скриншоты для сдачи»; «Наблюдения».
- «Материал для отчёта» в `NOTES.md`: замены инструментов, ошибки урока со страницами, твои решения, что не сделано.
- `HOMEWORK.md` **не создавай** — отчёт собирается после локального прогона.
- `TASK.md`: если был пуст — впиши туда пересказ задания своими словами (не копию урока).
- Коммит в рабочую ветку с понятным сообщением.

В конце сессии ответь мне коротко: сколько пунктов ✅ / ⚠️ / ❌, что сделать локально (одной строкой), и вопросы, если остались.
